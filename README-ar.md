# بلانر بيتي — نسخة PWA

الفولدر ده هو التطبيق كامل (ملف `index.html` فيه كل الأقسام والتصميم) + ملفات التثبيت:

| الملف | وظيفته |
|---|---|
| `index.html` | التطبيق نفسه |
| `manifest.webmanifest` | اسم التطبيق وأيقونته وشكل فتحه (بدون شريط المتصفح) |
| `sw.js` | بيخزّن الملفات عشان التطبيق يفتح بدون إنترنت |
| `pwa.js` | بيسجّل الـ service worker وبيطلب من المتصفح يحافظ على البيانات |
| `icons/` | أيقونات التطبيق (عادية + maskable لأندرويد) |
| `_headers` | إعدادات اختيارية لـ Netlify و Cloudflare Pages |

## النشر (اختاري واحدة)
1. **Netlify Drop** (أسرع واحدة): افتحي netlify.com/drop من الكمبيوتر، واسحبي الفولدر ده كله. هتاخدي رابط https فورًا.
   لازم تعملي حساب مجاني وتاخدي الموقع (Claim) بسرعة، وإلا الرابط بيتمسح.
2. **GitHub Pages**: ارفعي محتويات الفولدر في Repository جديد، وبعدين Settings ← Pages ← Deploy from branch (main / root).
3. **Cloudflare Pages**: Workers & Pages ← Create ← Pages ← Upload assets، وارفعي الفولدر.

## التثبيت على أندرويد
افتحي الرابط في **Chrome** ← القايمة (⋮) ← **تثبيت التطبيق** (Install app) ← تثبيت. هتلاقي الأيقونة في شاشة التطبيقات.

## البيانات
- بتتحفظ **على الجهاز بس** (localStorage جوه المتصفح). مفيش سيرفر ولا حساب ولا مزامنة بين الأجهزة.
- لو مسحتي بيانات Chrome أو شلتي التطبيق ومسحتي بياناته، البيانات بتضيع. استخدمي **المزيد ← أنا ← نسخة احتياطية** وانزّلي نسخة من وقت للتاني.
- لنقل بياناتك من نسخة لنسخة: «تنزيل نسخة» أو «نسخ كنص»، وبعدين «استرجاع من ملف» أو «لصق نص» في النسخة التانية.
- الخط (Cairo) بيتحمّل من Google Fonts أول مرة بنت وبيتخزّن. لو فتحتي التطبيق لأول مرة بدون نت هيظهر بخط النظام.

## لما تعدّلي حاجة وترفعي نسخة جديدة
ارفعي الفولدر على نفس المكان. التطبيق بيحدّث نفسه لوحده: أول فتح بعد الرفع بيحمّل النسخة الجديدة، والفتح اللي بعده بيعرضها.
